# Guitar MP3 프로젝트 분석 및 디자인 업데이트 계획서

## 1. 프로젝트 개요 및 분석

### 1.1 프로젝트 목적
- **서비스명**: Guitar MP3 (기타 트레이닝 플레이어)
- **주요 기능**: 기타 교재(예: '기초 기타 트레이닝 365일', '지옥의 베이직 기타 트레이닝')의 챕터별 예제 음원(모범 연주 및 반주 드럼 트랙)을 간편하게 재생하고, 구간 반복 및 배속 조절을 통해 기타 연습을 극대화하는 웹 애플리케이션.
- **주요 사용자**: 일렉트릭/어쿠스틱 기타 연습생 및 연주자.

### 1.2 기술 스택 현황
- **Core**: React 17, TypeScript, React Router Dom v5
- **상태 관리**: Zustand (`useCommon`)
- **스타일링**: Bootstrap 5, Sass (Dart Sass로 호환성 업데이트 완료), TailwindCSS v3, Emotion
- **아이콘**: MUI Icons Material (`@mui/icons-material`)

### 1.3 기존 디자인 및 UI/UX 취약점
1. **구식 기본 컴포넌트 의존**:
   - 기본 Bootstrap `btn-outline-primary` 및 단순 `ButtonGroup`, 무채색의 직사각형 카드로 구성되어 있어 음악 연습 전용 앱다운 매력이 부족함.
2. **브라우저 기본 `<audio controls>` 플레이어**:
   - 플랫폼/브라우저별로 파편화된 투박한 네이티브 회색 오디오 컨트롤러 노출.
   - 연습 중 필요한 정밀 프로그레스 바, 현재 시간/구간 시간 시각화 미흡.
   - 기타 연주 중 신속하게 조작할 수 있는 큼직한 재생 버튼 및 5초 뒤/앞 스킵 버튼 부재.
3. **탐색 및 사용성(UX) 한계**:
   - 챕터 목록이 50개 이상일 때 단순 세로 버튼 목록으로만 나열되어 스크롤 압박이 심하고 검색/필터 기능 부재.
   - 모범 연주와 반주(Backing Track)가 분리된 두 개의 오디오 바로 수직 배치되어 화면 공간 낭비 및 혼란 초래.
4. **시각적 아이덴티티(Visual Identity) 부재**:
   - 기타 앰프, 이펙터 페달, 스튜디오 콘솔을 연상시키는 현대적인 다크 테마 감성 부재.
   - 통일감 있는 글로벌 네비게이션 헤더 및 푸터 없음.

## 2. 디자인 시스템 및 UI 업데이트 계획

### 2.1 디자인 컨셉: "Modern Guitar Studio"
- **테마**: 딥 스튜디오 다크 (`#0f172a`, `#1e293b`, `#090d16`) + 일렉트릭 앰버/오렌지 포인트 (`#f59e0b`, `#f97316`) + 에메랄드/시안 액센트.
- **질감**: 글래스모피즘(Backdrop blur), 은은한 그라디언트 테두리, 부드러운 박스 섀도우.
- **타이포그래피**: `Noto Sans KR` (한글) + `Titillium Web` / `Inter` (숫자, 영문, BPM 표시).

### 2.2 핵심 개선 항목
1. **글로벌 레이아웃 & 네비게이션**:
   - 세련된 글래스모피즘 상단 네비게이션 바 (브랜드 로고, 기타 피크 아이콘, 홈 이동, 교재 바로가기).
   - 화면 최대 너비 최적화 및 모바일/데스크톱 완벽 반응형.
2. **교재 목록 화면 (`Books.tsx`)**:
   - 모던 히어로 배너 (기타 트레이닝 동기부여 문구, 전체 수록곡 요약 통계).
   - 프리미엄 앨범 카드 그리드 (교재 표지 스타일 그라디언트 카드, 챕터/레슨 수 뱃지, 트랙 정보).
3. **챕터 목록 화면 (`Book.tsx`)**:
   - 챕터 실시간 검색 인풋 (주차, 테마, 번호 빠른 필터링).
   - 주차별 카드/그리드 레이아웃과 직관적인 챕터 진입 인터페이스.
4. **커스텀 스튜디오 오디오 플레이어 (`StudioAudioPlayer.tsx`)**:
   - 브라우저 기본 플레이어를 대체하는 커스텀 UI.
   - **대형 원터치 재생/일시정지**, **-5초 / +5초 스킵**, **A-B 구간 루프 토글**.
   - **실시간 프로그레스 바 & 타임라인 마커** (클릭 및 드래그 탐색 지원).
   - **모범 연주 / 반주 트랙 탭 전환** (한눈에 비교하고 쉽게 스위칭).
   - **배속 조절 프리셋 & 마이크로 슬라이더** (0.5x ~ 1.2x 부드러운 피치/템포 연습).
   - **BPM 메트로놈 펄스 애니메이션** (재생 시 비트에 맞춘 시각 피드백).
5. **레슨 상세 화면 (`Chapter.tsx`)**:
   - 스티키 네비게이션 바 (이전 챕터 / 다음 챕터 퀵 스위치).
   - 세련된 레슨 카드 (BPM 뱃지, 구간 타임 태그, 깔끔한 제목 타이포그래피).
